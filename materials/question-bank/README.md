# 题库来源与使用声明

本目录收录的题库（`baseline-8` / `interview-core` / `mnc-60` / `meetings-core` / `cosmetics-meetings`）用于本项目的个人英语口语练习。

## 来源说明

- 题目素材整理自**互联网公开渠道**：社区面经分享、公开面试题汇总、公开招聘信息与常见岗位要求等；
- 收录时已做**通用化改写**（去除个人信息、机构名与具体项目细节），题面为高频问题的通用表述；
- 会议题库（`meetings-core` / `cosmetics-meetings`）为**原创编写**：话题提炼自公开行业报道与公开政策信息，题目、考察点、答题思路与追问均为本项目原创改写，不含任何来源的原文摘录，也不代表任何机构观点；
- 每题的考察意图（`intent`）、答题思路（`hint`）、追问（`followups`）等字段为本项目自行撰写；
- 本项目**不对题目原始出处主张任何权利**，也不保证与任何具体公司、机构的实际题库对应。
